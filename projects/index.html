할 일 관리 앱 ​

"내가 쓸 용도로 만든 심플한 할 일 앱"

기존 앱들이 너무 복잡해서, 정말 필요한 기능만 들어간 심플한 앱을 만들었습니다. React Hooks와 TypeScript를 제대로 활용해보고 싶어서 선택한 첫 번째 개인 프로젝트예요.

  • 핵심 기술: React, TypeScript, Tailwind CSS
  • 주요 배움: 상태 관리, 로컬 스토리지 활용, 컴포넌트 설계
  • 개발 기간: 약 3주 (2024.02~03)

VitePress 포트폴리오 (현재 사이트) ​

"마크다운으로 관리하는 개발 블로그"

단순한 포트폴리오가 아니라 지속적으로 학습 내용을 기록할 수 있는 공간이 필요했습니다. VitePress를 선택한 이유는 마크다운 기반으로 글을 쓰기 편하고, Vue.js도 경험해볼 수 있어서였어요.

  • 핵심 기술: VitePress, Vue.js, GitHub Actions
  • 주요 배움: 정적 사이트 생성, CI/CD 파이프라인, SEO 최적화
  • 개발 상태: 지속적인 개선 중

💻 GitHub

🔮 다음에 만들어보고 싶은 것들 ​

Next.js 블로그 플랫폼 ​

왜 만들고 싶나?
VitePress도 좋지만, 더 동적인 기능들(댓글, 좋아요, 검색 등)이 있는 블로그를 만들어보고 싶어요. Next.js의 SSR과 API Routes를 활용해서 풀스택 경험을 쌓고 싶습니다.

예상 기술 스택: Next.js, TypeScript, Prisma, PostgreSQL

개발자를 위한 유틸리티 도구 ​

왜 만들고 싶나?
개발하면서 자주 사용하는 작업들(JSON 포맷팅, 색상 코드 변환, 정규표현식 테스트 등)을 한 곳에 모아둔 도구가 있으면 편할 것 같아요.

예상 기술 스택: React, TypeScript, PWA

팀 프로젝트 경험 ​

왜 중요한가?
혼자 개발하는 것과 팀으로 개발하는 것은 완전히 다른 경험이라고 들었어요.
Git 협업, 코드 리뷰, 업무 분담 등을 실제로 경험해보고 싶습니다.

📚 개발하며 배운 것들 ​

  • React Hooks 패턴과 상태 관리의 복잡성

  • Git을 활용한 버전 관리와 배포 자동화
  • 반응형 디자인의 중요성과 구현 방법

  • 완벽함보다는 완성을 우선시하는 마인드
  • 문서화와 코드 주석의 필요성
