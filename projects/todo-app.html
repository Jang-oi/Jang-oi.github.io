🚀 할 일 관리 앱 ​

"내가 정말 쓸 만한 심플한 할 일 앱을 만들어보자!"

🎯 왜 만들었나? ​

기존 할 일 앱들의 문제점

  • 너무 많은 기능으로 인한 복잡함
  • 광고나 유료 결제가 필요한 기능들
  • 내 취향과 맞지 않는 디자인

내가 원했던 것

  • 정말 필요한 기능만 들어간 심플함
  • 빠르고 직관적인 사용성
  • 내 취향대로 커스터마이징 가능

React와 TypeScript를 제대로 사용해보고 싶어서 선택한 첫 번째 개인 프로젝트입니다.

개발 기간: 약 3주 (2024년 2월 ~ 3월)
GitHub: jang-oi/todo-app

🛠️ 사용한 기술들 ​

주요 기술

  • React - 컴포넌트 기반으로 UI 구성
  • TypeScript - 타입 에러 미리 잡기
  • Tailwind CSS - 빠른 스타일링
  • Vite - 개발 서버가 정말 빠름!

상태 관리

  • React Context API - 전역 상태 관리
  • localStorage - 브라우저에 데이터 저장

✨ 구현한 기능들 ​

핵심 기능 ​

  • ✅ 할 일 추가/수정/삭제
  • 🔍 완료/미완료 필터링
  • 🌙 다크모드 지원
  • 💾 새로고침해도 데이터 유지

사용자 경험 ​

  • 📱 모바일에서도 편하게 사용
  • ⚡ 빠른 반응속도
  • 🎨 깔끔하고 심플한 디자인

실제로 써보니

개발하고 나서 직접 몇 달간 사용해봤는데, 정말 필요한 기능만 있어서 오히려 더 편했어요. 복잡한 앱들보다 훨씬 빠르고 직관적입니다!

🛠️ 개발 과정 ​

1주차: 기본 틀 만들기 ​

뭘 했나?

  • React + TypeScript 프로젝트 생성
  • 기본적인 할 일 추가/삭제 기능 구현
  • 간단한 CSS로 스타일링

어려웠던 점

  • TypeScript 타입 정의가 생각보다 복잡했음
  • Context API 사용법이 처음엔 헷갈렸음

2주차: 기능 확장 ​

뭘 했나?

  • 완료/미완료 필터링 추가
  • localStorage로 데이터 지속성 확보
  • Tailwind CSS로 디자인 개선

삽질했던 부분

  • localStorage와 상태 동기화 타이밍 문제
  • 필터링 로직을 어디에 둘지 고민

3주차: 마무리 및 배포 ​

뭘 했나?

  • 다크모드 기능 추가
  • 모바일 반응형 디자인
  • Netlify 배포 및 테스트

뿌듯했던 점

  • 실제로 사용할 만한 앱이 완성됨
  • 친구들이 써보고 괜찮다고 피드백해줌

🤔 어려웠던 점들 ​

TypeScript 타입 정의 ​

문제상황
처음 TypeScript를 제대로 써보다보니 타입 정의가 어려웠어요. 특히 Context API와 함께 쓸 때 복잡했습니다.

어떻게 해결했나?

typescript
// 간단하게 시작해서 점점 복잡하게
interface Todo {
  id: string;
  text: string;
  completed: boolean;
  createdAt: Date;
}

type FilterType = 'all' | 'active' | 'completed';

localStorage 동기화 ​

문제상황
상태가 바뀔 때마다 localStorage에 저장하려고 했는데, 타이밍 문제로 데이터가 꼬이는 경우가 있었어요.

해결 방법
useEffect를 활용해서 상태가 변경될 때마다 자동으로 저장하도록 구현했습니다. 덕분에 새로고침해도 데이터가 유지되는 기능을 만들 수 있었어요.

📚 이 프로젝트를 통해 배운 것들 ​

기술적으로 배운 것 ​

  • React Hooks 패턴을 실제로 활용하는 방법
  • TypeScript가 런타임 에러를 어떻게 방지해주는지
  • Context API로 전역 상태를 관리하는 방법
  • localStorage 활용한 데이터 지속성

개발 프로세스에서 배운 것 ​

  • 완벽함보다는 완성이 중요하다는 점
  • 사용자 관점에서 기능을 생각하는 것의 중요성
  • 작은 단위로 개발하고 점진적으로 기능을 추가하는 방법

가장 뿌듯했던 점 ​

실제로 몇 달간 일상적으로 사용하고 있다는 점이에요.
복잡한 앱들보다 오히려 더 편하고, 필요한 기능만 딱 있어서 좋습니다.
