📝 할 일 관리 앱 ​

React와 TypeScript로 구현한 개인용 할 일 관리 애플리케이션

🎯 프로젝트 개요 ​

📋 기본 정보 ​

  • 프로젝트명: Personal Todo Manager
  • 개발 기간: 2024.02.01 ~ 2024.03.01 (약 1개월)
  • 개발 인원: 1명 (개인 프로젝트)
  • 상태: 완료 ✅

🚀 배포 링크 ​

  • 라이브 데모: https://your-todo-app.netlify.app
  • GitHub 저장소: https://github.com/jang-oi/todo-app

💡 프로젝트 동기 ​

기존의 할 일 관리 앱들이 너무 복잡하거나 원하는 기능이 부족해서 개인적으로 사용할 수 있는 심플하면서도 필요한 기능들을 갖춘 앱을 만들고 싶었습니다.

🎯 해결하고자 한 문제 ​

  • 복잡한 UI로 인한 사용성 저하
  • 오프라인에서도 사용 가능한 앱의 필요성
  • 개인 취향에 맞는 커스터마이징 부족

🛠️ 기술 스택 ​

Frontend ​

  • React 18.2 - 컴포넌트 기반 UI 구축
  • TypeScript 4.9 - 타입 안정성 확보
  • Tailwind CSS 3.2 - 빠른 스타일링

상태 관리 & 데이터 ​

  • React Context API - 전역 상태 관리
  • localStorage - 브라우저 로컬 저장소 활용

개발 도구 ​

  • Vite - 빠른 개발 환경 구축
  • ESLint + Prettier - 코드 품질 관리

🎨 주요 기능 ​

✨ 핵심 기능 ​

  1. 할 일 CRUD 작업

    • 할 일 추가, 수정, 삭제
    • 완료/미완료 상태 토글

  2. 필터링 및 정렬

    • 전체/완료/미완료 필터
    • 생성일 기준 정렬

  3. 다크 모드

    • 시스템 테마 자동 감지
    • 수동 테마 전환

  4. 로컬 저장

    • 브라우저 종료 후에도 데이터 유지
    • 새로고침 시 상태 복원

🚧 개발 과정 ​

1단계: 기획 및 설계 (1주차) ​

  • 요구사항 분석 및 기능 정의
  • UI/UX 스케치 및 와이어프레임
  • 기술 스택 선정

2단계: 개발 환경 구축 (1주차) ​

  • Vite + React + TypeScript 프로젝트 생성
  • Tailwind CSS 설정
  • ESLint, Prettier 설정

3단계: 핵심 기능 개발 (2주차) ​

  • Todo CRUD 기능 구현
  • Context API를 이용한 상태 관리
  • localStorage 연동

4단계: UI/UX 개선 및 배포 (1주차) ​

  • 반응형 디자인 적용
  • 다크 모드 구현
  • Netlify 배포
