목차

할 일 관리 앱 ​

개요 ​

  • 기간: 2024.02 ~ 2024.03 (약 3주)
  • 목적: 내가 실제로 쓸 수 있는 심플한 할 일 앱 만들기
  • 기술스택: React, TypeScript, Tailwind CSS, Vite
  • 링크: GitHub, 배포사이트

주요 기능 ​

  • 할 일 추가/수정/삭제
  • 완료/미완료 필터링
  • 다크모드 지원
  • 새로고침해도 데이터 유지 (localStorage)
  • 모바일 반응형

기술적 도전 ​

문제상황 1: TypeScript 타입 정의 ​

처음 TypeScript 제대로 써보는 건데 뭔가 타입 에러가 계속 나더라고요.
특히 Context API랑 같이 쓸 때 너무 복잡해서 포기하고 싶었어요.

해결과정 ​

일단 간단한 것부터 시작했어요.

typescript
// 복잡하게 하려다가 실패 -> 간단하게 시작
interface Todo {
  id: string;
  text: string;
  completed: boolean;
  createdAt: Date;
}

type FilterType = 'all' | 'active' | 'completed';

문제상황 2: localStorage 동기화 ​

상태 바뀔 때마다 localStorage에 저장하려고 했는데 타이밍이 안 맞아서 데이터가 꼬이는 경우가 있었어요.

해결과정 ​

useEffect 써서 상태 변경될 때마다 자동으로 저장하도록 했어요.
덕분에 새로고침해도 데이터가 유지되는 기능 만들 수 있었고요.

배운점 ​

  • TypeScript는 처음엔 귀찮지만 나중에 버그 잡아주니까 진짜 좋음
  • 완벽하게 하려고 하지 말고 일단 돌아가게 만든 다음에 개선하기
  • localStorage 활용하면 간단한 앱은 DB 없이도 충분함

아쉬웠던 점 ​

  • 카테고리 기능 넣고 싶었는데 시간 부족으로 못 함
  • 마감일 설정 기능도 있으면 좋을 것 같은데...
  • PWA로 만들어서 앱처럼 쓸 수 있게 하고 싶음

실제로 몇 달째 쓰고 있는데 복잡한 앱들보다 오히려 더 편해요!
