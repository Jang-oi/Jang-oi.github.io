프로젝트

실제 개발한 프로젝트들의 전체 과정을 기록합니다. 기획 단계부터 배포까지, 사용한 기술 스택과 해결한 문제들, 그리고 배운 점들을 솔직하게 공유합니다.

학습 노트

새로 배운 기술이나 개념들을 정리한 공간입니다. 딱딱한 문서보다는 개인 블로그처럼 편하게 작성하되, 나중에 다시 봐도 이해할 수 있도록 체계적으로 정리합니다.

포트폴리오

개발자로서의 정체성과 역량을 보여주는 공간입니다. 현재 보유한 기술 스택, 지금까지의 성장 과정, 그리고 앞으로의 목표를 담았습니다.

현재 진행 중 ​

최근 작업 ​

  • VitePress 포트폴리오 구축 - TypeScript + Vue 기반 정적 사이트 생성
  • JavaScript ES6+ 심화 학습 - 모던 자바스크립트 문법과 활용법 정리
  • React Hooks 패턴 연구 - 상태 관리와 사이드 이펙트 처리 방법론

학습 중인 기술 ​

  • TypeScript - 타입 시스템을 통한 안전한 코드 작성
  • React 18 - 최신 리액트 생태계와 개발 패턴
  • Vite - 빠른 빌드 도구와 개발 환경 구성

개발 철학 ​

"완벽한 코드보다는 지속 가능하고 유지보수 가능한 코드를,
혼자만의 성장보다는 함께 성장할 수 있는 개발자가 되고자 합니다."

새로운 기술을 배우는 것을 좋아하지만, 기술 자체보다는 문제 해결에 집중합니다.
코드를 통해 실제 사용자의 불편함을 해결하고, 더 나은 사용자 경험을 만드는 것이 목표입니다.
