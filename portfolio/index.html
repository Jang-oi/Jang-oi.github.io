🏗️ 주요 프로젝트 ​

1. 할 일 관리 앱 ​

React와 TypeScript로 구현한 개인용 태스크 관리 애플리케이션

주요 성과:

  • 완전한 CRUD 기능 구현
  • Context API를 활용한 전역 상태 관리
  • localStorage 연동으로 데이터 지속성 확보
  • 반응형 디자인으로 모바일 지원

기술 스택: React, TypeScript, Tailwind CSS, Context API

📂 프로젝트 상세보기 | 🔗 GitHub | 🌐 Live Demo

2. 포트폴리오 웹사이트 ​

VitePress 기반 개인 포트폴리오 및 기술 블로그

주요 성과:

  • 마크다운 기반 콘텐츠 관리 시스템 구축
  • 반응형 디자인으로 다양한 디바이스 지원
  • SEO 최적화로 검색 엔진 가시성 향상
  • GitHub Pages 자동 배포 파이프라인 구축

기술 스택: VitePress, Vue.js, Markdown, GitHub Actions
