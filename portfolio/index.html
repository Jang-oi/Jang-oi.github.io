👨‍💻 포트폴리오 ​

안녕하세요! 코드로 문제를 해결하는 것을 좋아하는 개발자 장정호입니다.

새로운 기술을 배우는 것보다는, 배운 기술로 실제 문제를 해결하는 과정에서 더 큰 즐거움을 느낍니다.
완벽하지 않더라도 일단 만들어보고, 개선해나가는 방식을 선호합니다.

🎯 개발 정체성 ​

"일단 만들어보는 개발자"

새로운 기술이 나오면 문서부터 읽는 것보다, 간단한 예제부터 만들어보며 익히는 스타일입니다.
에러가 나도 당황하지 않고, 문제를 하나씩 해결해나가는 과정을 즐깁니다.

🛠️ 주로 사용하는 기술들 ​

💻 Frontend ​

  • JavaScript (ES6+) - 가장 자주 쓰고 가장 편한 언어
  • React - 컴포넌트 기반 사고에 익숙해진 상태
  • TypeScript - 타입 에러 잡는 재미를 알게 된 후 적극 활용
  • HTML/CSS - 기본기는 탄탄하다고 자부함
  • Tailwind CSS - 빠른 스타일링을 위해 최근 주로 사용

🔧 개발 환경 & 도구 ​

  • Git/GitHub - 버전 관리와 협업의 기본
  • VS Code - 수많은 익스텐션과 함께하는 개발 환경
  • Vite - 빠른 개발 서버가 주는 쾌감
  • Chrome DevTools - 디버깅의 든든한 파트너

📚 현재 관심사 ​

  • Next.js - React 기반 풀스택 개발에 도전해보고 싶어서
  • 성능 최적화 - 사용자가 체감할 수 있는 속도 개선
  • 테스트 코드 - 안정적인 코드를 위한 필수 스킬

💡 개발하며 중요하게 생각하는 것들 ​

🎯 코드 품질 ​

  • 읽기 쉬운 코드 - 6개월 후의 나도 이해할 수 있는 코드
  • 일관된 스타일 - 팀원들과 약속한 규칙은 반드시 지키기
  • 적절한 주석 - 왜 이렇게 작성했는지에 대한 기록

🤝 협업 스타일 ​

  • 솔직한 소통 - 모르는 건 모른다고, 어려운 건 어렵다고 말하기
  • 적극적인 질문 - 혼자 해결하려다 시간 낭비하지 않기
  • 건설적인 피드백 - 비판보다는 개선 방향 제시

🚀 문제 해결 방식 ​

  • 작은 단위로 나누기 - 큰 문제를 작은 문제들로 분해
  • 검색과 문서 활용 - 구글링과 공식 문서 읽기 능숙
  • 직접 실험해보기 - 이론보다는 실제로 코드를 작성해서 확인

📈 개발자가 되기까지 ​

🎯 프로그래밍 시작 계기 ​

대학교에서 처음 배운 C언어가 너무 어려워서 포기할 뻔했는데,
웹 개발을 처음 접했을 때 브라우저에서 바로 결과를 확인할 수 있는 점이 매력적이었습니다.

💪 주요 학습 경험 ​

HTML/CSS 기초 다지기 (2022년 초)

  • 처음엔 div 태그만 써도 뿌듯했던 시절
  • CSS로 레이아웃 잡는 게 퍼즐 맞추기 같아서 재밌었음

JavaScript와의 첫 만남 (2022년 중)

  • 변수, 함수 개념부터 차근차근 학습
  • DOM 조작으로 웹페이지가 동적으로 변하는 걸 보고 감동

React 생태계 탐험 (2023년 초~현재)

  • 컴포넌트 기반 사고로 개발 방식이 완전히 바뀜
  • Hooks, Context API 등을 배우며 상태 관리의 중요성 깨달음

TypeScript 도입 (2023년 하반기)

  • 처음엔 귀찮았지만, 타입 에러로 버그를 미리 잡는 경험 후 필수가 됨
  • 협업 시 코드의 의도를 명확히 전달할 수 있어 좋음

🚀 만들어본 프로젝트들 ​

할 일 관리 앱 ​

왜 만들었나?
시중에 좋은 앱들이 많지만, 내가 원하는 기능만 딱 들어간 심플한 앱이 필요했어요.

기술적 도전

  • React Hooks를 활용한 상태 관리
  • TypeScript로 컴포넌트 인터페이스 정의
  • localStorage를 활용한 데이터 지속성
  • Tailwind CSS로 반응형 디자인

배운 점

  • 상태 관리의 복잡성과 Context API의 유용함
  • TypeScript가 런타임 에러를 줄여주는 경험
  • 사용자 경험을 고려한 UI/UX 디자인의 중요성

VitePress 포트폴리오 (현재 보고 있는 사이트!) ​

왜 만들었나?
단순한 정적 사이트가 아닌, 마크다운으로 쉽게 콘텐츠를 추가할 수 있는 블로그 형태가 필요했어요.

기술적 도전

  • VitePress 설정과 커스터마이징
  • GitHub Actions를 통한 자동 배포
  • SEO 최적화와 다국어 지원 구조
  • 마크다운 기반 콘텐츠 관리 시스템

배운 점

  • 정적 사이트 생성기의 장점과 활용법
  • CI/CD 파이프라인 구축 경험
  • 기술 블로그 운영의 가치
