📚 학습 노트 ​

"배운 건 정리해야 내 것이 된다!"

새로 배운 내용들을 나만의 방식으로 정리하는 공간입니다.
딱딱한 문서보다는 개인 블로그 느낌으로 편하게 작성하되, 나중에 다시 봤을 때도 이해할 수 있도록 정리합니다.

📝 작성된 학습 노트 ​

JavaScript ​

  • JavaScript ES6+ 핵심 정리 - 모던 JS 문법 정리

곧 추가될 노트들 ​

  • TypeScript 기초 - 타입 시스템 이해하기
  • React Hooks 패턴 - 실무에서 자주 쓰는 패턴들
  • Git 협업 - 브랜치 전략과 PR 작성법
  • Tailwind CSS - 유틸리티 클래스 활용법

💡 내가 학습하는 방식 ​

1. 일단 써보기 ​

새로운 기술을 배울 때 문서부터 읽지 않고, 간단한 예제부터 따라해봅니다.
실제로 작동하는 걸 보면서 "아, 이런 식으로 동작하는구나" 하고 감을 잡는 편이에요.

2. 궁금한 점 정리하기 ​

따라하다보면 "왜 이렇게 되지?" 싶은 부분들이 생겨요.
그럴 때마다 따로 메모해두고, 나중에 하나씩 찾아보면서 정리합니다.

3. 내 방식으로 정리하기 ​

공식 문서나 블로그들은 너무 딱딱한 경우가 많아서,
내가 이해한 방식으로 다시 정리하는 편입니다. 그래야 나중에 다시 봐도 이해가 돼요.

4. 실제 프로젝트에 적용하기 ​

배운 건 바로 개인 프로젝트나 연습 프로젝트에 적용해봅니다.
실제로 써보면서 "아, 이럴 때 유용하구나" 하고 체득하는 것 같아요.

🔥 최근에 관심 있는 주제들 ​

Next.js ​

React를 어느 정도 익혔으니 이제 Next.js를 배워보고 싶어요.
SSR, API Routes 등 풀스택 개발에도 도전해보고 싶습니다.

성능 최적화 ​

사용자가 체감할 수 있는 성능 개선에 관심이 많아졌어요.
번들 사이즈 줄이기, 이미지 최적화, 로딩 시간 단축 등등.

테스트 코드 ​

지금까지는 브라우저에서 직접 테스트하는 방식이었는데,
자동화된 테스트 코드 작성법을 배우고 싶습니다.
