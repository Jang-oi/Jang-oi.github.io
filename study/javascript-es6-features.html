오늘 배운 것: JavaScript ES6+ 문법들 ​

날짜: 2024.02.15
상태: 완료

뭘 하려고 했는지 ​

React 프로젝트 하는데 남들 코드 보면 뭔가 문법이 다르더라고요. const, let, 화살표 함수 이런 것들...
"이것도 자바스크립트야?" 싶어서 ES6+ 문법들을 제대로 배워보기로 했어요.

과정 ​

첫 번째: let과 const ​

  • 처음엔 "var랑 뭐가 다르지?" 생각했는데...
  • for문에서 setTimeout 쓸 때 이상한 현상 겪음
  • 결과: 아 이래서 let을 쓰는구나!
javascript
// 이렇게 했는데 결과가 이상했음
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100); // 3, 3, 3 출력... 왜지?
}

// let으로 바꿨더니 해결!
for (let i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100); // 0, 1, 2 출력!
}

두 번째: 화살표 함수 ​

  • 처음엔 "=>" 이게 뭔가 싶었는데
  • map, filter 쓸 때 진짜 편하더라고요
  • 결과: 이제 없으면 답답함
javascript
// 예전에 이렇게 썼는데...
const doubled = numbers.map(function(n) {
  return n * 2;
});

// 이렇게 하니까 훨씬 깔끔!
const doubled = numbers.map(n => n * 2);

세 번째: 템플릿 리터럴 ​

  • 문자열 합치는 게 너무 복잡했는데
  • 백틱(`)으로 ${} 이렇게 쓰니까 진짜 편함
  • 특히 여러 줄 문자열도 쉽게!
javascript
// 전에는 이랬는데...
const message = "안녕하세요, " + name + "님! 나이는 " + age + "살이군요.";

// 이제는 이렇게!
const message = `안녕하세요, ${name}님! 나이는 ${age}살이군요.`;

네 번째: 구조 분해 할당 ​

  • 처음 봤을 때 "이게 뭐야?" 했는데
  • 객체에서 값 꺼내는 게 진짜 편해짐
  • API 응답 처리할 때 특히 유용!
javascript
// 예전 방식
const name = user.name;
const email = user.email;
const age = user.age;

// 새로운 방식
const { name, email, age } = user;

// 배열에서도 가능
const [first, second, third] = colors;

다섯 번째: 스프레드 연산자 ​

  • "..." 점 세 개가 뭔가 했는데
  • 배열 복사하거나 합칠 때 진짜 유용함
  • 객체도 쉽게 복사/병합 가능!
javascript
// 배열 합치기
const allFruits = [...fruits, ...vegetables];

// 객체 병합 (이거 진짜 자주 씀)
const config = { ...defaultConfig, ...userConfig };

느낀 점 ​

  • 처음엔 "굳이?" 싶었는데 써보니까 코드가 진짜 깔끔해짐
  • React 코드 볼 때 이해가 안 됐던 부분들이 다 이해됨
  • 특히 구조 분해 할당은 진짜 혁신적이었어요
  • 이제 예전 문법으로 돌아가기 싫을 정도로 편함

자주 헷갈리는 부분들 ​

  1. 화살표 함수 this 바인딩 - 아직도 가끔 헷갈림
  2. 구조 분해 할당에서 기본값 - 문법이 좀 특이함
  3. 스프레드 vs Rest - 같은 문법인데 용도가 다름

다음에 더 알아볼 것 ​

  • async/await (비동기 처리가 더 쉬워진다던데...)
  • Promise 제대로 이해하기
  • 클래스 문법 (아직 잘 안 써봄)
