📚 JavaScript ES6+ 핵심 정리 ​

"처음엔 어려웠지만 지금은 없으면 안 되는 모던 JS 문법들"

ES6 이후로 추가된 JavaScript 문법들을 정리한 노트입니다.
처음 배울 때 헷갈렸던 부분들과 실제로 사용해보니 유용했던 점들을 위주로 정리했어요.

💡 왜 이 내용들을 정리했나? ​

프로젝트를 하면서 ES5 문법만 쓰다가 ES6+ 문법을 제대로 배우니까 코드가 훨씬 깔끔해졌어요.
특히 React 프로젝트를 할 때 이런 문법들을 모르면 정말 답답하더라고요.

자주 사용하는 것들 위주로 정리해봤습니다!

1. let과 const - 이제 var는 안 써도 돼요 ​

왜 배우게 됐나? ​

var만 쓰다가 for문에서 setTimeout 쓸 때 이상한 현상을 겪었어요.
분명히 0, 1, 2가 출력될 줄 알았는데 3, 3, 3이 나오더라고요. 그때 알게 된 게 let이었습니다.

실제 경험한 문제 ​

javascript
// 이렇게 했는데 결과가 이상했음
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100); // 3, 3, 3 출력... 왜지?
}

// let으로 바꿨더니 해결!
for (let i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100); // 0, 1, 2 출력!
}

내가 사용하는 규칙 ​

  1. 일단 const로 시작 - 대부분의 변수는 재할당이 필요 없음
  2. 재할당이 필요하면 let - 반복문 카운터나 조건에 따라 값이 바뀌는 경우
  3. var는 절대 안 쓰기 - 예상치 못한 버그의 원인
javascript
// 내가 자주 쓰는 패턴
const API_URL = "https://api.example.com";  // 상수
const users = [];  // 배열 내용은 바뀌지만 변수 자체는 재할당 안 함

let currentPage = 1;  // 페이징에서 재할당 필요
let isLoading = false;  // 상태값이 바뀜

2. 화살표 함수 - 짧고 간결해서 좋아요 ​

왜 좋아하게 됐나? ​

처음엔 문법이 이상해보였는데, map, filter 같은 배열 메서드 쓸 때 진짜 편하더라고요.
특히 React에서 컴포넌트 만들 때 거의 필수가 된 것 같아요.

자주 사용하는 패턴들 ​

javascript
// 배열 메서드에서 진짜 유용함
const numbers = [1, 2, 3, 4, 5];
const doubled = numbers.map(n => n * 2);  // 간결!
const evens = numbers.filter(n => n % 2 === 0);  // 깔끔!

// 한 줄로 끝나는 함수는 return 생략
const greet = name => `안녕, ${name}!`;
const add = (a, b) => a + b;

// 객체 반환할 때는 괄호로 감싸기
const createUser = name => ({ name, createdAt: Date.now() });

this 바인딩이 달라서 주의해야 할 점 ​

javascript
const user = {
  name: "장정호",
  
  // 일반 함수: this가 user 객체
  sayHello: function() {
    console.log(`안녕, ${this.name}`);  // 정상 작동
  },
  
  // 화살표 함수: this가 상위 스코프 (여기서는 window나 undefined)
  sayBye: () => {
    console.log(`잘가, ${this.name}`);  // undefined 나올 수 있음
  },
  
  // setTimeout에서는 오히려 화살표 함수가 유용
  delayedGreeting: function() {
    setTimeout(() => {
      console.log(`늦은 인사: ${this.name}`);  // 정상 작동!
    }, 1000);
  }
};

3. 템플릿 리터럴 ​

📝 개념 정리 ​

백틱(`)을 사용하여 문자열을 더 편리하게 작성할 수 있는 기능입니다.

💡 실습 예제 ​

javascript
const name = "장정호";
const age = 25;
const hobby = "개발";

// 기본 사용법
const introduction = `안녕하세요! 저는 ${name}이고, ${age}살입니다.`;

// 다중 라인 문자열
const emailTemplate = `
  안녕하세요, ${name}님!
  
  새로운 업데이트가 있습니다:
  - 기능 개선
  - 버그 수정
  - 성능 최적화
  
  감사합니다.
`;

// 표현식 활용
const mathResult = `2 + 3 = ${2 + 3}`;
const conditional = `당신은 ${age >= 18 ? '성인' : '미성년자'}입니다.`;

// 함수 호출
const formatDate = (date) => date.toLocaleDateString('ko-KR');
const today = `오늘은 ${formatDate(new Date())}입니다.`;

// 태그 템플릿 (고급 기능)
function highlight(strings, ...values) {
  return strings.reduce((result, string, i) => {
    const value = values[i] ? `<mark>${values[i]}</mark>` : '';
    return result + string + value;
  }, '');
}

const highlighted = highlight`제 이름은 ${name}이고 취미는 ${hobby}입니다.`;
// "제 이름은 <mark>장정호</mark>이고 취미는 <mark>개발</mark>입니다."

4. 구조 분해 할당 ​

📝 개념 정리 ​

배열이나 객체에서 값을 추출하여 개별 변수에 할당하는 문법입니다.

💡 실습 예제 ​

javascript
// 배열 구조 분해
const colors = ['red', 'green', 'blue', 'yellow'];
const [primary, secondary, tertiary, ...rest] = colors;

console.log(primary);   // 'red'
console.log(secondary); // 'green'
console.log(rest);      // ['yellow']

// 기본값 설정
const [a, b, c = 'default'] = ['first', 'second'];
console.log(c); // 'default'

// 객체 구조 분해
const user = {
  id: 1,
  name: '장정호',
  email: 'jang@example.com',
  preferences: {
    theme: 'dark',
    language: 'ko'
  }
};

const { name, email, age = 25 } = user;
const { preferences: { theme } } = user; // 중첩 구조 분해

// 변수명 변경
const { name: userName, email: userEmail } = user;

// 함수 매개변수에서 활용
function createUser({ name, email, age = 18 }) {
  return {
    id: Date.now(),
    name,
    email,
    age,
    createdAt: new Date()
  };
}

const newUser = createUser({
  name: '김개발',
  email: 'kim@example.com'
});

// React에서 자주 사용하는 패턴
function UserProfile({ user: { name, email, avatar } }) {
  return `
    <div class="profile">
      <img src="${avatar}" alt="${name}" />
      <h2>${name}</h2>
      <p>${email}</p>
    </div>
  `;
}

5. 스프레드 연산자 ​

📝 개념 정리 ​

배열이나 객체를 펼쳐서 개별 요소로 분리하거나 병합할 수 있는 연산자입니다.

💡 실습 예제 ​

javascript
// 배열에서의 스프레드
const fruits = ['사과', '바나나'];
const vegetables = ['당근', '양파'];
const food = [...fruits, ...vegetables, '쌀'];
// ['사과', '바나나', '당근', '양파', '쌀']

// 배열 복사
const originalArray = [1, 2, 3];
const copiedArray = [...originalArray]; // 얕은 복사
copiedArray.push(4);
console.log(originalArray); // [1, 2, 3] (원본 보존)

// 객체에서의 스프레드
const defaultConfig = {
  theme: 'light',
  language: 'ko',
  notifications: true
};

const userConfig = {
  theme: 'dark',
  fontSize: 14
};
