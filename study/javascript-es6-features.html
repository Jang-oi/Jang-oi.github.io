1. let과 const ​

📝 개념 정리 ​

ES6에서 도입된 새로운 변수 선언 키워드로, 기존 var의 문제점들을 해결합니다.

🔍 주요 특징 ​

키워드스코프재선언재할당호이스팅
var함수OO가능
let블록XO불가
const블록XX불가

💡 실습 예제 ​

javascript
// var의 문제점
console.log(hoisted); // undefined (호이스팅)
var hoisted = "문제 있음";

for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 10); // 3, 3, 3 출력
}

// let과 const로 해결
// console.log(notHoisted); // ReferenceError
let notHoisted = "정상 작동";

for (let i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 10); // 0, 1, 2 출력
}

// const 활용
const API_URL = "https://api.example.com";
const user = { name: "장정호", age: 25 };

// user = {}; // TypeError (재할당 불가)
user.age = 26; // 가능 (객체 내부 수정)

  • 루프에서는 let 사용 - 클로저 문제 해결

2. 화살표 함수 ​

📝 개념 정리 ​

더 간결한 함수 문법을 제공하며, this 바인딩이 다르게 동작합니다.

💡 실습 예제 ​

javascript
// 기본 문법
const add = (a, b) => a + b;
const square = x => x * x; // 매개변수가 하나일 때 괄호 생략
const greet = () => "안녕하세요!"; // 매개변수가 없을 때

// 여러 줄 함수
const processUser = (user) => {
  const processed = {
    ...user,
    fullName: `${user.firstName} ${user.lastName}`,
    timestamp: Date.now()
  };
  return processed;
};

// this 바인딩의 차이
const obj = {
  name: "장정호",
  
  // 일반 함수 - this가 obj를 가리킴
  regularFunction: function() {
    console.log(`안녕, ${this.name}`); // "안녕, 장정호"
  },
  
  // 화살표 함수 - this가 상위 스코프를 가리킴
  arrowFunction: () => {
    console.log(`안녕, ${this.name}`); // "안녕, undefined"
  },
  
  // 실용적인 사용 예시
  delayedGreeting: function() {
    setTimeout(() => {
      console.log(`늦은 인사, ${this.name}`); // "늦은 인사, 장정호"
    }, 1000);
  }
};

3. 템플릿 리터럴 ​

📝 개념 정리 ​

백틱(`)을 사용하여 문자열을 더 편리하게 작성할 수 있는 기능입니다.

💡 실습 예제 ​

javascript
const name = "장정호";
const age = 25;
const hobby = "개발";

// 기본 사용법
const introduction = `안녕하세요! 저는 ${name}이고, ${age}살입니다.`;

// 다중 라인 문자열
const emailTemplate = `
  안녕하세요, ${name}님!
  
  새로운 업데이트가 있습니다:
  - 기능 개선
  - 버그 수정
  - 성능 최적화
  
  감사합니다.
`;

// 표현식 활용
const mathResult = `2 + 3 = ${2 + 3}`;
const conditional = `당신은 ${age >= 18 ? '성인' : '미성년자'}입니다.`;

// 함수 호출
const formatDate = (date) => date.toLocaleDateString('ko-KR');
const today = `오늘은 ${formatDate(new Date())}입니다.`;

// 태그 템플릿 (고급 기능)
function highlight(strings, ...values) {
  return strings.reduce((result, string, i) => {
    const value = values[i] ? `<mark>${values[i]}</mark>` : '';
    return result + string + value;
  }, '');
}

const highlighted = highlight`제 이름은 ${name}이고 취미는 ${hobby}입니다.`;
// "제 이름은 <mark>장정호</mark>이고 취미는 <mark>개발</mark>입니다."

4. 구조 분해 할당 ​

📝 개념 정리 ​

배열이나 객체에서 값을 추출하여 개별 변수에 할당하는 문법입니다.

💡 실습 예제 ​

javascript
// 배열 구조 분해
const colors = ['red', 'green', 'blue', 'yellow'];
const [primary, secondary, tertiary, ...rest] = colors;

console.log(primary);   // 'red'
console.log(secondary); // 'green'
console.log(rest);      // ['yellow']

// 기본값 설정
const [a, b, c = 'default'] = ['first', 'second'];
console.log(c); // 'default'

// 객체 구조 분해
const user = {
  id: 1,
  name: '장정호',
  email: 'jang@example.com',
  preferences: {
    theme: 'dark',
    language: 'ko'
  }
};

const { name, email, age = 25 } = user;
const { preferences: { theme } } = user; // 중첩 구조 분해

// 변수명 변경
const { name: userName, email: userEmail } = user;

// 함수 매개변수에서 활용
function createUser({ name, email, age = 18 }) {
  return {
    id: Date.now(),
    name,
    email,
    age,
    createdAt: new Date()
  };
}

const newUser = createUser({
  name: '김개발',
  email: 'kim@example.com'
});

// React에서 자주 사용하는 패턴
function UserProfile({ user: { name, email, avatar } }) {
  return `
    <div class="profile">
      <img src="${avatar}" alt="${name}" />
      <h2>${name}</h2>
      <p>${email}</p>
    </div>
  `;
}

5. 스프레드 연산자 ​

📝 개념 정리 ​

배열이나 객체를 펼쳐서 개별 요소로 분리하거나 병합할 수 있는 연산자입니다.

💡 실습 예제 ​

javascript
// 배열에서의 스프레드
const fruits = ['사과', '바나나'];
const vegetables = ['당근', '양파'];
const food = [...fruits, ...vegetables, '쌀'];
// ['사과', '바나나', '당근', '양파', '쌀']

// 배열 복사
const originalArray = [1, 2, 3];
const copiedArray = [...originalArray]; // 얕은 복사
copiedArray.push(4);
console.log(originalArray); // [1, 2, 3] (원본 보존)

// 객체에서의 스프레드
const defaultConfig = {
  theme: 'light',
  language: 'ko',
  notifications: true
};

const userConfig = {
  theme: 'dark',
  fontSize: 14
};
